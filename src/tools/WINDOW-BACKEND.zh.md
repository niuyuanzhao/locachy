# 直连程序以窗口显示

[English](WINDOW-BACKEND.md)

基础库程序（term、settings、view、files）都画在软件画布上。在自己的屏幕上时，它们经 DRM 显示，输入设备由进程 1 出借。同一程序也可以在共享桌面上以普通窗口显示。只有受信任的窗口启动器能选择这一方式，方法是设置 `LOCACHY_BACKEND=wayland`；其他取值以及未设置时，都走原来的直连路径，行为不变。

## 选择是显式的，失败即关闭

- `direct`（或未设置）：屏幕和设备与以前完全一样。
- `wayland`：xdg-shell 窗口。不打开 DRM 节点或输入设备，也不使用租约或进程 1 控制通道。
- 程序构建时未包含窗口后端，或变量取了其他值：退出状态 78。请求窗口时没有合成器，或合成器没给出窗口：退出状态 69。两种情况都不会改为打开 DRM 或输入设备。

进程 1 和 initramfs 用 musl 构建，不含任何窗口代码。`make.sh` 只把窗口后端（`CONFIG_WAYLAND`）编进会开窗口的程序，而且只在已安装桌面模块的 Wayland 库时才编入。

## 窗口的行为

- **边框**：窗口向合成器请求由它绘制边框（`zxdg_decoration_manager_v1`，服务端）：带标题以及关闭、最大化、最小化按钮的标题栏。窗口不请求时，labwc 不画边框。
- **没有自己的顶栏**：状态由桌面自己的顶栏显示，所以窗口里没有 LOCachy 顶栏。画布在窗口上方保留顶栏占用的行，程序的排版因此和在屏幕上完全一样，第一行内容紧贴窗口上沿。在窗口中 `screen_bar` 什么都不画，这些行也从不显示。指针位置以画布像素计；按住按键时窗口上方的点为负值，落在画布之外。
- **画面**：画布尺寸等于窗口在首选分数缩放下的像素尺寸（`wp_fractional_scale_v1` 配合 `wp_viewporter`；否则用整数缓冲缩放）。每次尺寸变化（包括第一次 configure）都以 `K_SHOWN` 通知程序，和换屏一样，程序随之重新排版。画面用 `wl_shm` 缓冲显示，同时最多一帧在途；合成器仍在显示上一帧时画好的画面，等该帧完成后再提交。合成器让程序自定尺寸时，窗口初始为 1100x760 逻辑像素；若合成器建议的范围更小，就缩到该范围内。
- **按键**：来自 seat 的键盘，使用合成器的 keymap（输入法也经同一方式送出文字），并支持 XKB compose 序列和按键重复。按键会转换成与屏幕上相同的基础库键码：方向键和功能键、Ctrl+字母、Ctrl+数字，ASCII 以外的文字为 `K_TEXT`。全局快捷键（home、锁屏、输入法、音量）由合成器处理，不会传到窗口。
- **指针**：支持移动、按键、双击和三击、滚轮步进；触控板滚动的步长与屏幕上相同。光标由合成器绘制。
- **就绪**：第一次显示画面时，向启动器的 `LOCACHY_WINDOW_READY_FD` 写入一个字节，然后关闭它。子进程不会继承这个描述符。
- **关闭**：点击关闭按钮或触发合成器的关闭快捷键，不会直接结束程序，而是以按键 `K_CLOSE`（`base.h`）交给程序，由程序走自己的退出流程，因此进行中的工作（复制、软件包安装）不会被中断。程序还没读到 `K_CLOSE` 时再次关闭，不会再多出一个。
  - 程序有意保持打开（工作进行中、有未保存的更改）时，读到 `K_CLOSE` 后调用 `key_close_kept()`。下一次关闭会是新的 `K_CLOSE`。
  - 安全网：程序读到 `K_CLOSE` 后 3 秒内再次关闭，且其间没有调用 `key_close_kept()`，程序立即结束（退出状态 0）。这是为还不认识 `K_CLOSE` 的程序准备的。超过 3 秒后，关闭又是一个新的 `K_CLOSE`。
  - 合成器消失时，窗口无法再显示，程序以退出状态 69 结束。

选区、剪贴板和从窗口拖出文件由数据设备负责（`base/wayland-data.c`），它使用本窗口的连接、seat、surface 和输入事件 serial。

## 测试

`tools/test-window-backend.sh 新的绝对目录` 需在装有 labwc 的一次性测试根中运行。它启动一个私有 headless labwc，不用物理输入或显示器，然后检查：

- 三种拒绝情形（退出状态 78、78、69）；
- 就绪字节和第一次 configure；
- 没有打开 DRM 或输入设备；
- 输出上的画面（截图），其中没有程序自己的顶栏；
- 协商到服务端边框，窗口位于其标题栏下方；
- 虚拟设备发送的按键和点击；
- 最大化后的尺寸变化；
- 用 Alt+F4 关闭：
  - 程序收到 `K_CLOSE` 并继续运行；
  - 调用 `key_close_kept()` 后，快速的第二次关闭是另一个 `K_CLOSE`；
  - 超过 3 秒后的关闭是另一个 `K_CLOSE`；
  - 3 秒内的第二次关闭结束程序。

它不覆盖以下内容：

- 用指针点击边框上的关闭按钮（Alt+F4 发出的是同一个请求）；
- 分数输出缩放；
- 触摸输入；
- 运行中的输入法；
- 各窗口程序自身的布局（settings、files、view）；
- 真机。
