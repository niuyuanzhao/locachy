# 自适应充电

[English](BATTERY-CHARGING.md)

**设置 → 电源与电池**中的自适应充电默认关闭，原有手动启停阈值仍可使用。在支持
的硬件上，开启后会根据本机的电池历史识别长时间插电的使用习惯，把充电目标维持在
约 80%，而不是一直充满。如果观察到可靠的拔电规律，会提前允许充到 100%。已经
超过目标的电池不会被主动放电。没有足够观测时，保留正常充电行为或已配置的手动值。

接通电源时，可选 **现在充满** 临时把目标提到 100%。它不会更改手动设置或清空历史；
拔电或达到界面显示的期限（最多 24 小时）后结束。固件自身的充电策略或温度限制仍
可能推迟充电。

现有的 `battery-history` 服务管理阈值，并读回硬件实际接受的值。睡眠、关机和缺失的
AC 记录不算持续插电的证据；系统不会单为调整目标而唤醒。关闭自适应后恢复手动值，
未设置的字段恢复接管前的值。自动控制要求当前只有一块系统电池，且能读取电池身份及
Linux 标准充电上限；不会假定多块电池有独立控制器。电池读数、历史以及硬件已有的手动
设置仍可使用。没有明确 AC 读数的旧历史仍可查看，但不会用于学习。

## 配置

- `battery_charge_adaptive="0"`：支持的硬件上设为 `"1"` 才启用。
- `battery_charge_start`、`battery_charge_end`：保存的手动启停百分比。
- `battery_charge_full_until`：由 **现在充满** 写入的临时期限，不是永久充电上限。

软件回归用带时间的历史数据检查策略，用模拟电源设备检查阈值写入、读回和恢复。这些
测试不能代替对具体笔记本固件实际停充、恢复充电的验证。
